## About

This repository contains the five certification projects completed as part of the **freeCodeCamp Python v9 Certification**.

Each project demonstrates a core Python concept — from object-oriented programming and data structures to recursion and algorithm design.

## Project Summaries

### 1. Settings Manager
A dictionary-based settings system that supports adding, updating, deleting, and viewing user settings. Demonstrates clean use of Python dictionaries and input validation.

### 2. Budget App
A budget tracking application built with classes. Supports deposits, withdrawals, transfers between categories, and generates a visual spending chart. Demonstrates object-oriented programming and string formatting.

### 3. Polygon Area Calculator
A `Rectangle` class with full geometry methods (area, perimeter, diagonal, picture) and a `Square` subclass that inherits from it. Demonstrates class inheritance and method overriding.

### 4. Hash Table
A custom hash table implementation with add, remove, and lookup operations. Uses character-based hashing and handles collisions with nested dictionaries. Demonstrates low-level data structure design.

### 5. Tower of Hanoi Solver
A recursive solution to the classic Tower of Hanoi problem. Tracks and returns every move state as disks are transferred from rod A to rod C. Demonstrates recursion and algorithm thinking.
